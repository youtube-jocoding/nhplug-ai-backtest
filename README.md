# AI 자동매매, 과거에 해봤다면?

아래 프롬프트를 복사해서 Codex에 붙여넣으면 됩니다.

```text
https://github.com/youtube-jocoding/nhplug-ai-backtest 를 받아서 AI 백테스트를 실행할 수 있게 해줘.

나는 개발을 모르는 사람이야. README.md, AGENTS.md, WORKFLOW.md를 읽고 내려받기부터 설치·테스트·실행까지 직접 진행해줘. 터미널 명령을 입력하거나 파일을 편집하라고 하지 마.

기존 자동매매 코드를 실행하지 말고, 별도의 폴더에 이 백테스트 예제만 설치해. Python 3.10 이상과 curl, 정상 Codex CLI를 확인하고 bootstrap.py를 실행해. 필요하면 설치를 도와줘. 로그인이나 관리자 승인이 필요하면 내가 해야 하는 화면 동작만 알려줘.

setup.py --open으로 로컬 설정 화면을 열어줘. NH 앱키·앱시크릿은 내가 그 화면에 직접 넣을 거야. 키를 채팅에 요구하거나 출력하지 말고, 다른 프로젝트의 키를 임의로 가져오지 마. NH 키가 없다면 공식 포털의 이용 신청·발급이 먼저 필요하다고 안내해줘.

내가 화면에서 키 연결과 AI 사용량 안내에 동의한 뒤 시작 버튼을 누르면, NH 과거 주가 조회부터 Codex 판단·백테스트·결과 화면까지 이어지도록 해줘. 처음에는 기본 예제로 진행하고, 실제 데이터나 AI 실행에 실패하면 샘플로 바꾸지 말고 원인을 알려줘.

완료되면 날짜별 판단 이유와 가상 거래 내역을 보여줘. 실제 주문은 하지 마. 현재 AI로 과거를 다시 분석한 실험이며 실제 투자 성과가 아니고, 모델·시점에 따라 영상과 결과가 다를 수 있다는 점도 알려줘.
```

## 처음 한 번, 직접 해야 하는 것

1. Codex 설치·로그인과 사용 가능한 이용량.
2. 본인 NH Namuh PLUG 이용 신청·앱키 발급. [공식 안내](https://www.nhplug.com/intro)를 확인하세요.
3. Codex가 연 **로컬 화면에 키 입력 → 연결 확인 → 동의 후 시작**.

코딩·터미널 입력은 Codex가 처리합니다. 로그인·키 발급·사용자 승인은 대신할 수 없습니다.
아무 계정이나 키 없이 프롬프트 한 번만으로 실제 시세를 사용할 수 있다는 뜻은 아닙니다.

## 무엇을 보여주나요?

**NH 과거 주가 → AI 판단 → 다음 거래일 가상 체결 → 판단 이유와 결과**

- [이전 자동매매 예제](https://github.com/youtube-jocoding/nhplug-auto-trader)의 지표·판단 규칙을 재사용합니다.
- 삼성전자 1종목, 2026년 9월 14~23일(8거래일), 하루 1회 판단으로 단순화합니다. 시연용 종목이지 추천이 아닙니다.
- 가상 투자금 100만원, 1회 매수 예산 30만원, 편도 비용 0.1% 가정. 실제 NH 요율이 아닙니다.
- **실제 계좌 조회·주문 기능이 없습니다.** 매도 없이 보유 중이면 결과는 평가손익입니다.
- AI가 기다리라고 판단하면 거래 0건도 정상입니다. 영상의 수익률이나 매수 날짜를 보장하지 않습니다.
- 결과 화면은 저장된 실제 AI 판단을 재생합니다. 버튼마다 새 AI를 호출하지 않습니다.

키 연결 화면에서 시작하면 시세 조회와 AI 판단을 순서대로 진행합니다. 수 분 걸릴 수 있습니다.
완료 후 결과 화면에서 날짜를 선택하거나 체결 표를 눌러 이유를 확인하세요.
시세 없이 살펴보려면 **“가상 데이터로 화면만 먼저 보기”**를 선택하세요. 실제 결과와 구분합니다.

## 개발자용 실행

Python 3.10 이상, curl, 로그인된 최신 Codex CLI가 필요합니다. 계산·화면은 표준 라이브러리만 사용합니다.

```sh
python3 bootstrap.py
.venv/bin/python setup.py --open
# Windows: .venv\Scripts\python.exe setup.py --open
```

macOS 기본 Python이 3.9이면 정상 Python 3.10 이상 경로로 실행하세요.
설치 절차는 [WORKFLOW.md](WORKFLOW.md)에 있습니다.
[Codex CLI 설치](https://developers.openai.com/codex/cli) · [로그인 안내](https://developers.openai.com/codex/auth)

설정 화면은 127.0.0.1에만 열리고 10분 1회용 링크로 인증합니다. 기본 8771 포트가 사용 중이면 빈 포트를 선택합니다.
공개 서버에 올리지 마세요. 창을 닫아도 프로세스는 계속될 수 있으므로 종료는 Codex에 요청하세요.

## 보관·보안

키·토큰은 로컬 `private/`에 저장되며 **암호화 저장소가 아닙니다**. macOS/Linux에서 소유자 전용 파일 권한을 사용합니다. 공유 PC에서는 사용하지 마세요. Windows 파일 권한 강화·전체 실동작은 아직 별도 검증 대상입니다.
가격·AI 기록은 `datasets/`, `cache/`, `runs/`에 보관합니다. 이 폴더와 `.env`, `.venv`는 Git에서 제외합니다. 작업 폴더 전체를 공유하지 마세요.
AI에는 과거 가격·지표·가상 보유 상태만 전달하며 NH 인증정보는 전달하지 않습니다. NH 데이터 재배포 권한을 제공하는 저장소가 아닙니다.

## 한계

현재 AI는 이후 정보를 알고 있을 수 있어 당시 투자 결정을 재현하지 못합니다. 과거·모의 결과는 미래 수익을 보장하지 않습니다.
배당·세금 별도 계산·슬리피지·시장충격·체결 불가 상황은 반영하지 않습니다. 평가 기간의 배당락이나 미지원 권리 이벤트는 중단합니다.
NH 공식 완성형 백테스트 서비스가 아니라 과거 시세 API를 이용한 교육용 코드입니다. 광고 심의가 코드·성과를 보증하지 않습니다.

## 테스트와 파일

```sh
.venv/bin/python -m unittest discover -v
```

테스트는 가상 키·가상 API로 진행하고 실제 API나 AI를 호출하지 않습니다.
실제 키 없이도 설치·설정 화면·오류 처리·계산은 검증할 수 있습니다. 실제 NH/AI 연결은 본인 키·로그인으로 별도 확인해야 합니다.

GitHub Actions는 자동 활성화되어 있지 않습니다. [CI 예제](docs/ci-template.yml)를 워크플로 권한이 있는 계정으로 `.github/workflows/tests.yml`에 배치하면 Python 3.10·3.12 테스트가 실행됩니다.

| 파일 | 역할 |
|---|---|
| bootstrap.py | 가상환경 생성·테스트·실행 환경 확인 |
| setup.py | 키 입력·인증·실제 실행·진행 상황 |
| engine.py / upstream/strategy.py | 과거 입력·판단 규칙·가상 계산 |
| nh_client.py / nh_data.py | 읽기 전용 NH 시세 조회 |
| ai_provider.py | Codex 판단·검증·기록 |
| server.py / web | 결과 화면·샘플·기록 재생 |
| WORKFLOW.md | Codex가 수행할 초보자 설치 절차 |
