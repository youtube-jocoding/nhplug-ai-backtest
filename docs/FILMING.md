# 3분 촬영 순서
1. 이전 영상 연결: “과거에 이렇게 투자했다면 결과가 어땠을까요?”
2. README 프롬프트 복사 → Codex에 붙여넣기. 설치·키 설정은 압축 편집. 키는 촬영하지 않는다.
3. 키 연결 후 AI 백테스트 시작. 최초 실행은 수 분 걸릴 수 있다.
4. 결과 화면에서 대기·매수 판단과 다음 거래일 체결을 보여준다. 실제 결과에 맞춰 설명한다.
5. “실제 돈을 넣기 전에 내 전략을 과거 주가로 시험해 볼 수 있습니다.”

자막: 지금의 AI로 과거를 재분석한 결과이며 당시 실제 투자와 같지 않습니다.
원본 전체 재현이 아니라 단일 종목·하루 한 번 판단으로 단순화한 예제다.
결과 화면 버튼은 저장된 판단의 재생이다. 새 AI 생성처럼 편집하지 않는다.
손익은 미청산 보유분 포함 평가손익이며 수익성을 입증하지 않는다.
광고 고지·심사필은 별도 승인된 소재 기준으로 반영한다.
