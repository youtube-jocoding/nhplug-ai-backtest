# 촬영 순서
1. README 프롬프트로 별도 설치·환경 확인을 Codex에 맡긴다.
2. 빈 NH 키 연결 화면에서 시작한다. 키 입력 부분은 촬영하지 않는다.
3. 연결 확인 후 실제 주가를 준비한다. 여기서는 아직 AI를 호출하지 않는다.
4. 조건과 AI에게 할 말을 보여 주고 이용량 동의 후 AI 판단으로 백테스트를 실행한다.
5. 날짜별 이유와 다음 거래일 가상 매매를 보여 준다. 거래가 없으면 그대로 설명한다.
6. 프롬프트나 손절·익절 등을 수정해 다시 실행한다. 같은 기간·시작 자금의 두 실험 그래프와 같은 날짜 판단을 비교한다.

기록 보기에는 새 AI 호출이 없다. AI 판단 실행 버튼은 매번 새 호출을 한다.
지금의 AI로 과거를 재분석한 실험이며 당시 실제 투자 성과가 아니다. 모델·실행 시점에 따라 영상과 결과가 다를 수 있다.
미청산 보유분을 포함한 평가손익이다. 공식 기본 수수료·세율은 반영하지만 계좌별 우대와 절사 방식, 미체결·슬리피지 등은 재현하지 않는다.
광고 고지·심사필은 별도 승인된 소재 기준으로 반영한다.
