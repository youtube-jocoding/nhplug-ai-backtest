# 검증 범위 (2026-10-09)

- macOS, Python 3.12, 로그인된 Codex CLI와 본인 NH 키로 검증했습니다.
- GitHub에서 새 폴더로 다운로드 → bootstrap.py → 로컬 웹 키 입력 → 실제 NH 인증 → 과거 시세 400개 조회 → 새 AI 판단 8개 → 결과 화면 → 날짜·체결 선택 → JSON 다운로드를 실행했습니다.
- 기존 시세·AI 캐시는 새 설치에 복사하지 않았습니다. 키 발급·Codex 로그인 자체는 기존 자격으로 진행했으므로 신규 가입·OS 설치 전 과정을 검증했다는 뜻은 아닙니다.
- 단위·HTTP 테스트 45개. 개인 자료 없는 첫 설치는 44개 통과·실제 개인 데이터 재생 1개 건너뜀. 실제 데이터 생성 후 45개 통과.
- Git 없이 ZIP 다운로드한 사본에서도 가상환경 생성·테스트가 통과했습니다.
- 테스트용 Chromium에서 1440×1000, 390×844 확인. 키 입력 후 값 삭제, 동의 전 실행 차단, 날짜·차트 선택, 다운로드, 입력 변경 시 결과 삭제, 캐시 누락 시 중단을 검사했습니다.
- 실험 결과는 고정 정답이 아닙니다. AI 버전·실행 시점에 따라 다를 수 있습니다.
- 실제 주문 기능 없음. 키·토큰·시세·개인 결과는 공개 저장소와 ZIP에 포함하지 않았습니다.
- Windows/Linux 전체 실동작, 신규 계정의 승인·가입, 모든 네트워크 환경은 검증하지 않았습니다.
- GitHub Actions 자동 CI는 인증 권한 제한으로 비활성입니다. ci-template.yml은 설치용 예제입니다.
